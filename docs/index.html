Bitcoin Timelock Wallet

Create time-locked Bitcoin addresses using Taproot. Funds can only be spent after a specific block height.

How It Works

  • Create: Generate address locked until a block height
  • Fund: Send BTC to the address from any wallet
  • Wait: Funds locked until blockchain reaches target
  • Spend: After unlock, spend to any destination

Security

  • All crypto runs in your browser - keys never leave
  • Download backup JSON - it contains your private key!

Networks

Testnet4 (recommended) | Testnet3 | Signet | Mainnet | Regtest
